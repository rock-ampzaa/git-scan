# README

## DESCRIPTION
为方便管理本地的多个git开发目录，防止遗漏提交，故而开发这个**简陋**的小工具

目前的工具由两个程序组成
- `read-dir-list`负责接收命令行参数，解析'目录列表文件', 并把解析之后的结果输出到标准输出
- `scan-git` 从命令行中接收一个路径，对该路径中的文件是否 新建/删除/修改/改名、本地分支是否领先跟踪分支、整个仓库是否没有上游 等进行检查。并把检查到的问题显示在标准输出
## USAGE
常用方式是用管道与`xargs`将两个程序组合起来
```
read-dir-list -f <目录列表文件> | xargs -I[] scan-git []
```
- `read-dir-list -h`  可以查看更多
- `read-dir-list` 如果以`scan-need-git-op`的别名启动，自动设置输入文件为`~/git-scan-dirs`
## 目录列表文件的格式
```
# '#'开头的是注释
# 末尾是'/*': 表示指定目录下的所有子目录
# 可以使用'~'表示用户主目录
~/project/*
# 指定特定目录
~/document/xx_document

# 排除条目 在最开始放一个'!'
!~/document/exclude
!~/document/exclude/*
```
